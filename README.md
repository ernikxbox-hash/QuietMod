# Quiet Mod 👁️

Telegram Business бот — перехватывает удалённые и изменённые сообщения. Чёрный люкс.

## Возможности

- 🕵️ **Перехват удалённых и изменённых сообщений** (Business API) — безлимит
- ✨ **Премиум-эмодзи в меню** — кастомные эмодзи из пака `CPT_Emoji`: в тексте меню и **иконками на кнопках** (`icon_custom_emoji_id`, Bot API 9.4). Работает у всех пользователей, у подписчиков Premium — анимированные
- 🎤 **Расшифровка голосовых** (Groq Whisper) с кнопкой «Тык»
- 🤖 **ИИ-консьерж без лимитов** (Llama 4 Maverick Vision + Llama 3.3 70B) — с поиском в интернете, погодой и работой с фото
- 💤 **AFK-автоответ** — включается прямо в ЛС с ботом
- 🔇 **Mute** — удалять сообщения собеседника в личке
- 🛡️ **WBL-фильтр** — удаляет мат, обфускацию и флуд от собеседника
- 💻 **Режим кода** — всё, что пишешь, оформляется как код
- 🔍 **`.search`** — поиск через DuckDuckGo + ИИ (погода в том числе)
- 💰 **`.price`** — оценка стоимости юзернейма (как на Fragment)
- ⚔️ **`.knb`** — камень-ножницы-бумага: в ЛС с собеседником и в группах по вызову (`.knb @user` → кнопка «⚔️ Принять бой»), со счётом на реваншах
- 🛡️ **`.nomute`** — анти-анти-мут: твои сообщения в бизнес-чате пересылаются через бота и становятся невидимы для чужих мутеров
- 👀 **`.peek N`** — фейковая «печатает…» на N секунд: индикатор от твоего имени, никто не поймёт, что это фейк
- ✏️ **Форматирование**: `.bold` `.italic` `.mono` `.line` `.crossed` `.hidden` `.quote`
- 📚 **Архив безлимитный** — для всех, навсегда
- ◐ **Поиск по архиву** — включён для всех
- 📢 **Рассылки** админом: всем пользователям или по группам/каналам
- ⟡ **Поддержка развития** — добровольный вклад 15/30/50⭐ (бот бесплатен и без лимитов)

## Команды

### В ЛС с ботом

| Команда | Что делает |
|---|---|
| `/start` | Главное меню |
| `.afk` | Включить AFK — все, кто пишет в твоих бизнес-чатах, получат автоответ «я не в сети» (в подтверждении — кнопка «🔴 Выключить AFK») |
| `.afk текст` | AFK с заметкой — она приложится к автоответу (пример: `.afk вернусь через час`) |
| `.unafk` | Выключить AFK (сбрасывает AFK и во всех бизнес-чатах) |
| `.peek [N]` | Показать «печатает…» в бизнес-чате (выбери чат кнопкой). `.peek stop` — остановить |
| `.spam текст N` / `.spam stop` | N одинаковых сообщений в текущий чат |

### В бизнес-чатах (инлайн-команды, пишутся прямо в чате)

| Команда | Что делает |
|---|---|
| `.afk [заметка]` | Автоответ «я не в сети» (для этого чата) |
| `.mute` / `.unmute` | Удалять все сообщения собеседника |
| `.nomute` / `.unomute` | Анти-анти-мут: твои сообщения идут через бота — чужие муты их не видят |
| 👀 `.peek N` | Показывать «печатает…» N секунд (стелс, от твоего имени) |
| `.wbl` / `.unwbl` | Фильтр мата и флуда |
| `.code` / `.uncode` | Режим кода |
| `.ai вопрос` | ИИ-ответ (работает с текстом и фото) |
| `.search запрос` | Поиск + ИИ (погода: `.search погода в Москве`) |
| `.price @username` | Оценка юзернейма (без аргумента — оценит собеседника) |
| ⚔️ `.knb` | Камень-ножницы-бумага с собеседником: секретные ходы, случайный первый ход, счёт на реваншах |
| `.bold/.italic/.mono/.line/.crossed/.hidden/.quote текст` | Форматирование |
| `.spam текст N` / `.spam stop` | Рассылка (с кнопкой «⛔ Остановить») |

> В группах и каналах работают: `.ai`, `.search`, `.price`, форматирование, `.spam` и ⚔️ `.knb @user` (вызов на бой 1×1 с кнопкой «Принять бой»).

## Структура

```
bot.py          # точка входа: init БД, синк чатов, запуск polling, graceful shutdown
core.py         # конфигурация: env-переменные, bot/dp, логгер, FSM-состояния
database.py     # слой данных (aiosqlite + SQLite): 7 таблиц, батчеры записи, лимиты архива
business_api.py # HTTP-обёртки Business-методов Telegram Bot API
functions.py    # общая логика: ИИ (Groq + ротация ключей), поиск, погода, WBL-фильтр, клавиатуры
handlers.py     # все обработчики: перехват, инлайн-команды, ЛС-меню, админ-панель, платежи
tasks.py        # фоновая очистка просроченных сохранённых сообщений (каждые 6 ч)
requirements.txt
Procfile        # Railway / Heroku
railway.toml    # Railway: volume для data/bot.db
.env.example    # переменные окружения (создай по таблице ниже)
```

## Деплой на Railway

### 1. Подготовка

```bash
# Залей проект на GitHub (приватный репо)
git init
git add .
git commit -m "init"
git remote add origin https://github.com/ТВОЙuser/quiet-mod-bot.git
git push -u origin main
```

### 2. Railway

1. Зайди на [railway.app](https://railway.app)
2. New Project → Deploy from GitHub repo → выбери репо
3. Перейди в Variables → добавь:

| Key | Value |
|-----|-------|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_ID` | твой Telegram ID |
| `GROQ_API_KEY` | ключ от [console.groq.com](https://console.groq.com) |
| `GROQ_API_KEY2` | второй ключ от Groq (запасной, необязательно) — если на первом лимит/ошибка, бот переключится на второй |

> `BOT_USERNAME` захардкожен в `core.py` — из переменной окружения не читается.

4. Volumes → Add Volume → Mount path: `/app/data`
   (это сохраняет БД между перезапусками)

5. Deploy → бот запустится автоматически

### 3. Проверка

Напиши `/start` боту — должно прийти приветствие.
Администратору придёт сообщение `✔ Бот запущен`.

## Как работает бизнес-перехват

1. Пользователь подключает бота в Telegram Business → Автоматизация чатов
2. Все входящие сообщения проходят через `@dp.business_message()` → сохраняются в SQLite (батчером, архив безлимитен для всех)
3. При удалении — `@dp.deleted_business_messages()` → бот достаёт из БД и отправляет владельцу (медиа пересылает, голосовые расшифровывает)
4. При редактировании — `@dp.edited_business_message()` → уведомление «Было / Стало»
5. Если владелец включил AFK (в ЛС с ботом или в самом чате) — собеседникам отправляется автоответ «Я сейчас не в сети.» (+ заметка)

## Как работает AFK из ЛС с ботом

1. Напиши боту в личку: `.afk` или `.afk ушёл по делам`
2. Все, кто тебе пишет в подключённых бизнес-чатах, получат автоответ
3. Чтобы выключить: напиши `.unafk` (или `.unafk` прямо в бизнес-чате)

> AFK из ЛС действует на **все** бизнес-чаты сразу. AFK, включённый в конкретном чате (`.afk` там), действует только на этот чат.

## Как работает 👀 `.peek`

Напиши в бизнес-чате: `.peek 10` — собеседник увидит «печатает…» ровно 10 секунд.

- Индикатор отправляется через твоё бизнес-подключение и показывается **от твоего имени** —
  это не «Бот печатает», а как будто печатаешь ты сам
- Сама команда `.peek` **мгновенно удаляется** — собеседник её не видит
- Переотправка каждые 4 секунды (индикатор живёт ~5 секунд), так что «печатает…» не мигает
- Как только ты реально отправишь сообщение — фейк останавливается сам (как у настоящего человека)

**Из ЛС с ботом:** напиши `.peek 15` — бот покажет кнопки с твоими бизнес-чатами, выбери нужный —
и там начнётся «печатает…». Если бизнес-чат один — стартует сразу. `.peek stop` — остановить всё.

> Чтобы бот «узнал» твои бизнес-чаты, напиши в каждом хотя бы раз после запуска бота
> (или попроси собеседника написать) — бот запомнит их для `.peek` из ЛС.

## Как работает анти-мут 🛡️ `.nomute`

Если собеседник подключил своего бота, который **мутит тебя** (удаляет твои сообщения) —
Telegram скрывает от него сообщения, отправленные другими ботами. Этим и пользуемся:

1. Включи в чате: `.nomute` (или `.nomute off` → `.unomute`)
2. Каждое твоё сообщение бот **мгновенно пересылает через твоё бизнес-подключение**
   (копия выглядит как твоё обычное сообщение) и **удаляет оригинал** — дублей нет
3. Чужой мут-бот такую копию **не видит и не удаляет** — твои сообщения доходят

> Работает с текстом, фото, видео и любыми файлами. Команды (`.ai`, `.mute` и т.п.)
> пересылке не подлежат — они работают как обычно.

## Как играть в ⚔️ `.knb`

**В ЛС (Business):** напиши `.knb` в чате с собеседником — игра начнётся сразу: секретные ходы, случайный первый ход, реванши.

**В группе:** напиши `.knb @ник_соперника` — бот покажет вызов, а соперник примет бой кнопкой **«⚔️ Принять бой»**. Играют 1×1, все видят, но ходы остаются секретными (соперник видит только «сделал ход 🤫»).

- Кнопки хода: ✊ ✌️ 🖐
- Кто ходит первым — решает случай, каждый раунд заново
- На реваншах ведётся **счёт**: `@ты 3:1 @соперник`
- В группе бот должен быть **админом**, чтобы видеть сообщения участников
